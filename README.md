# Borrower Narratives as a Selective Signal in Credit Default Forecasting

Replication package for the manuscript *Borrower Narratives as a Selective Signal in Credit
Default Prediction: Evidence from Korean Online Lending* (under review; earlier working
title: *Borrower Narratives as a Selective Signal in Credit Default Forecasting*).

The study asks **when** borrower-written narratives add value to credit-default forecasts
beyond a strong structured baseline. Using 6,057 consumer loan applications from a Korean
lending platform, it compares a structured-only CatBoost (CAT) model with an otherwise
identical text-merged counterpart across 50 repeated stratified splits, and evaluates the
incremental value of text along four operating dimensions: prediction uncertainty, borrower
risk segment, decision threshold, and narrative informativeness.

**Headline result:** no statistically significant improvement in ranking metrics (ROC-AUC,
PR-AUC) is detected in any analysis; the contribution of text is confined to default
detection (Recall), concentrated in ambiguous prediction regions, at moderate thresholds
(0.4–0.5), and among borrowers in the top 30% of credit scores — arguably where structured
variables are least informative about impending default in this sample. Under the
Nadeau–Bengio (2003) variance correction for repeated resampling — the manuscript's primary
inference standard — none of the positive text effects remains statistically significant
(`results/raw/nb_corrected_all.csv` reports corrected t/p for all 41 Table 5–9 effects), so
the conditional pattern is reported as descriptive, exploratory evidence. A calibration
analysis (manuscript Figure 3) shows the structured-only model is approximately calibrated
(ECE ≈ 0.050; Brier 0.173 vs. 0.173 for text-merged) and that 66% of its false negatives at
τ = 0.5 fall inside the [0.3, 0.7] marginal band (43.7% of observations). Dense sentence
embeddings (MiniLM, KoSimCSE) do not improve on TF–IDF: they significantly degrade ranking
in the overall sample and in both uncertainty regions (manuscript Appendix I). A fold-internal
re-preprocessing robustness check (manuscript Appendix II) shows that the full-sample
preprocessing used in the main design is immaterial: refitting all preprocessing within each
training partition shifts text-merged performance by at most 1 × 10⁻³ on any metric
(ROC-AUC +0.00032; the largest, F1, +0.00091; all nominal p ≥ 0.29) and changes no conclusion.
Two additional checks respond to review feedback: a maturity-restricted sensitivity run that
drops the two most recent application-year cohorts (181 loans, all non-default; the nominal
Recall gain disappears, Δ = +0.0011, nominal p = 0.35 — `09_maturity_sensitivity.py`), and a
gating-candidate reconstruction (text activated only inside the [0.3, 0.7] band: −1.80 FN,
+2.10 FP per test set on average, corrected p = 0.49 — `10_gating_candidate.py`).
`11_cohort_restricted_full.py` additionally repeats every conditional analysis (Tables 6–9,
calibration, gating) on the restricted 5,876-loan sample: no corrected-standard conclusion
changes, while point estimates attenuate (the Low-Risk FN reduction disappears).

## Reproducing the results

```bash
pip install -r requirements.txt
cd code
python 01_analysis_unified.py   # ≈ minutes on a laptop CPU; rewrites results/raw/
python 02_make_tables.py        # rewrites results/tables/tables_5_9.md
python 03_make_figures.py       # rewrites figures/Fig2, Fig4, Fig5
python 04_make_fig1.py          # rewrites figures/Fig1
python 07_calibration.py        # rewrites results/raw/calibration_*.csv
python 08_make_fig5.py          # rewrites figures/Fig3 (calibration)
python 09_maturity_sensitivity.py  # rewrites results/raw/maturity_sensitivity_t5.csv
python 10_gating_candidate.py   # rewrites results/raw/gating_candidate.csv
python 11_cohort_restricted_full.py  # rewrites results/raw/restricted_*.csv
```

Verification without re-training is also possible: `results/raw/` ships with the exact
per-seed records used in the manuscript, so steps `02`–`03` can be run directly against them.
The embeddings-appendix summary (`results/tables/appendix_b_table.md`) is likewise reproducible from
`results/raw/rob_*.csv`; the dense embedding matrices behind `05_robustness_embeddings.py`
are derived from confidential narrative texts and are available on reasonable request.
The fold-internal script (`06_robustness_fold_internal.py`) requires the confidential raw
narrative file and is provided for transparency; the per-seed outputs it produced
(`results/raw/foldint_t{5,6,7}.csv`) are included, and its summary is in
`results/tables/appendix_c_table.md`. The algorithm-selection stage behind manuscript
Table 4 is not part of the released scripts.

## Experimental design (fixed for all reported comparisons)

| Component | Specification |
|---|---|
| Sample | N = 6,057 (default rate 55.34%) |
| Splits | stratified 80/20 train/test, `random_state = seed`, seeds 1–50 |
| Model (both configurations) | `CatBoostClassifier(iterations=100, depth=5, learning_rate=0.1, auto_class_weights='Balanced', random_state=42)` |
| Configurations | structured-only (13 features) vs. text-merged (13 + 100 features) |
| Classification threshold | 0.5, except the threshold-sensitivity analysis (τ ∈ {0.3,…,0.7}) |
| Uncertainty band (D1) | structured-only p̂ ∈ [0.3, 0.7]; the same subset evaluates both models |
| Risk tiers (D2) | credit-score bottom 30% (High-Risk) / top 30% (Low-Risk) per test set |
| Informativeness (D4) | Rich = ≥1 nonzero TF–IDF feature; Sparse = none |
| Inference | Nadeau–Bengio (2003) corrected paired t-tests (primary; variance × (1/J + n_test/n_train)); nominal seed-wise paired t-tests and 95% CIs reported descriptively |

## Requirements

Python ≥ 3.10 with `catboost`, `scikit-learn`, `pandas`, `numpy`, `scipy`, `matplotlib`
(tested versions pinned in `requirements.txt`). Results are deterministic given the pinned
seeds; minor last-digit differences may occur across CatBoost versions. The fold-internal script
additionally uses `konlpy` (Okt) on the confidential raw texts.

## Data statement

The underlying loan-level data were obtained from a Korean lending platform under a
confidentiality agreement. This repository releases only de-identified, model-ready inputs
(quantile-transformed numeric features and anonymized TF–IDF term indices) that contain no personal
information and no narrative text. The transformed files cannot reproduce the raw-scale
descriptive statistics in manuscript Table 3; `results/table3_raw_summary.csv` provides
that verification aggregate. See `data/README.md` for details.
