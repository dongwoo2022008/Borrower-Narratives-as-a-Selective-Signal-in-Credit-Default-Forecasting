# Borrower Narratives as a Selective Signal in Credit Default Forecasting

Replication package for the manuscript *Borrower Narratives as a Selective Signal in Credit
Default Forecasting* (under review).

The study asks **when** borrower-written narratives add value to credit-default forecasts
beyond a strong structured baseline. Using 6,057 consumer loan applications from a Korean
lending platform, it compares a structured-only CatBoost (CAT) model with an otherwise
identical text-merged counterpart across 50 repeated stratified splits, and evaluates the
incremental value of text along four operating dimensions: prediction uncertainty, borrower
risk segment, decision threshold, and narrative informativeness.

**Headline result:** text never improves ranking metrics (ROC-AUC, PR-AUC); its contribution
is confined to default detection (Recall), concentrated in ambiguous prediction regions,
at moderate thresholds (0.4–0.5), and among borrowers with strong credit scores — precisely
where structured variables are most likely to miss impending default.

## Repository layout

```
├── code/
│   ├── 01_analysis_unified.py   # main analysis → results/raw/ (per-seed records, Tables 5–9)
│   ├── 02_make_tables.py        # Tables 5–9 with paired t-tests and 95% CIs → results/tables/
│   ├── 03_make_figures.py       # Figures 2–4 → figures/
│   └── 04_make_fig1.py          # Figure 1 (pipeline diagram) → figures/
├── data/                        # de-identified model inputs (see data/README.md)
│   ├── structured_features.csv  # 6,057 × 13 standardized structured features
│   ├── tfidf_features_sparse.csv# sparse triplets (row_id, term_id, value) of the TF–IDF block
│   └── labels.csv               # binary default outcome
├── results/
│   ├── raw/                     # per-seed outputs of 01 (seeds 1–50), incl. Figure 2 histogram data
│   └── tables/tables_5_9.md     # final Tables 5–9 as reported in the manuscript
└── figures/                     # Figure 1 editable source; PNGs are generated by the scripts
```

## Reproducing the results

```bash
pip install -r requirements.txt
cd code
python 01_analysis_unified.py   # ≈ minutes on a laptop CPU; rewrites results/raw/
python 02_make_tables.py        # rewrites results/tables/tables_5_9.md
python 03_make_figures.py       # rewrites figures/Fig2–4
python 04_make_fig1.py          # rewrites figures/Fig1
```

Verification without re-training is also possible: `results/raw/` ships with the exact
per-seed records used in the manuscript, so steps `02`–`03` can be run directly against them.

## Experimental design (fixed for all reported comparisons)

| Component | Specification |
|---|---|
| Sample | N = 6,057 (default rate 55.34%) |
| Splits | stratified 80/20 train/test, `random_state = seed`, seeds 1–50 |
| Model (both configurations) | `CatBoostClassifier(iterations=100, depth=5, learning_rate=0.1, auto_class_weights='Balanced', random_state=42)` |
| Configurations | structured-only (13 features) vs. text-merged (13 + 100 features) |
| Classification threshold | 0.5, except the threshold-sensitivity analysis (τ ∈ {0.3,…,0.7}) |
| Uncertainty band (D1) | structured-only p̂ ∈ [0.3, 0.7]; the same subset evaluates both models |
| Risk tiers (D2) | credit-score bottom 30% (High-Risk) / top 30% (Low-Risk) per test set |
| Informativeness (D4) | Rich = ≥1 nonzero TF–IDF feature; Sparse = none |
| Inference | seed-wise paired two-sided t-tests; 95% CIs |

## Requirements

Python ≥ 3.10 with `catboost`, `scikit-learn`, `pandas`, `numpy`, `scipy`, `matplotlib`
(tested versions pinned in `requirements.txt`). Results are deterministic given the pinned
seeds; minor last-digit differences may occur across CatBoost versions.

## Data statement

The underlying loan-level data were obtained from a Korean lending platform under a
confidentiality agreement. This repository releases only de-identified, model-ready inputs
(standardized numeric features and anonymized TF–IDF term indices) that contain no personal
information and no narrative text. See `data/README.md` for details.
