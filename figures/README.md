# Figures

The manuscript figures are generated by the scripts in `code/`:

- Figure 1: `python code/04_make_fig1.py` → `Fig1_research_pipeline.png`
- Figures 2, 4, 5: `python code/03_make_figures.py` (requires `results/raw/`, which ships with the repository)
- Figure 3 (calibration): `python code/08_make_fig5.py` (requires `results/raw/calibration_bins.csv`, `calibration_seed.csv`)

Running the scripts writes the PNG files into this directory exactly as they appear in the manuscript.
Effect figures (4 and 5) display Nadeau–Bengio-corrected 95% confidence intervals (see manuscript Section 3.6).
