# Figures

- `Fig1_research_pipeline.drawio` — editable source of Figure 1 (open with diagrams.net).
- The manuscript figures are generated by the scripts in `code/`:
  - Figure 1: `python code/04_make_fig1.py` → `Fig1_research_pipeline.png`
  - Figures 2–4: `python code/03_make_figures.py` (requires `results/raw/`, which ships with the repository)

Running the two scripts writes the PNG files into this directory exactly as they appear in the manuscript.
